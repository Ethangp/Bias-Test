# Bias-Test

Pattern Check is a Next.js app for reflection-based tests about dating, friendships, bias, conflict, and compatibility.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the app.

## Structure

- `src/app/` contains the pages and layout.
- `src/components/` contains shared UI.
- `src/lib/` contains quiz data, scoring, and storage helpers.
